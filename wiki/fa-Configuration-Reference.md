# مرجع تنظیمات

هرچه رابط کاربری می‌تواند تنظیم کند در یک فایل JSON ذخیره می‌شود، تا بشود خواندش، diff گرفت، در گیت
نگه داشت و با دست ویرایش کرد. این صفحه آن را کامل مستند می‌کند.

## کجا ذخیره می‌شود

| پلتفرم | مسیر |
| --- | --- |
| مک | `~/Library/Application Support/net.nanternet.monitor/targets.json` |
| لینوکس | `~/.config/net.nanternet.monitor/targets.json` |
| ویندوز | `%APPDATA%\net.nanternet.monitor\targets.json` |

نوشتن اتمیک است: محتوای جدید در یک فایل همسایه با پسوند `.staging` نوشته می‌شود و بعد روی فایل اصلی
rename می‌شود. پس یک ذخیره نیمه‌کاره نمی‌تواند فایل ناقص و بدون مورد پایش برایتان جا بگذارد.

برنامه فایل را یک بار در زمان بالا آمدن می‌خواند. اگر وقتی برنامه در حال اجراست با دست ویرایشش کنید،
اولین ذخیره از سمت رابط کاربری تغییراتتان را بازنویسی می‌کند. اول از برنامه خارج شوید.

## سطح بالا

```json
{
  "targets": [],
  "settings": {}
}
```

هر دو کلید اختیاری هستند؛ فایل غایب یا کلید نبوده یعنی هیچ موردی و تنظیمات پیش‌فرض.

## مورد پایش

```json
{
  "id": "9f2c1e64-6b9a-4c0e-9f1a-8e5d3c7b2a10",
  "name": "سایت شرکت",
  "enabled": true,
  "intervalSecs": 120,
  "spec": {}
}
```

| فیلد | نوع | پیش‌فرض | توضیح |
| --- | --- | --- | --- |
| `id` | رشته | تولید می‌شود | یک UUID. وقتی با دست مورد اضافه می‌کنید خالی بگذارید تا در اولین ذخیره ساخته شود. عوض کردنش رمز ذخیره‌شده را بی‌صاحب می‌کند. |
| `name` | رشته | الزامی | چیزی که در فهرست و در هشدارها می‌آید. فاصله‌های ابتدا و انتها حذف می‌شود. |
| `enabled` | بولین | `true` | مقدار `false` بررسی را متوقف می‌کند بدون از دست رفتن تنظیمات. |
| `intervalSecs` | عدد | `120` | ثانیه بین دو بررسی، کف ۱۵. |
| `spec` | آبجکت | الزامی | با فیلد `kind` تفکیک می‌شود. |

## spec وب‌سایت

```json
{
  "kind": "website",
  "url": "https://example.ir",
  "externalProbe": true,
  "externalIntervalSecs": 900,
  "expectedStatus": null,
  "expectedBody": null,
  "iranNodes": 3,
  "abroadNodes": 4
}
```

| فیلد | نوع | پیش‌فرض | توضیح |
| --- | --- | --- | --- |
| `url` | رشته | الزامی | اگر اسکیم نداشته باشد `https://` به ابتدایش اضافه می‌شود. |
| `externalProbe` | بولین | `true` | خاموش کردنش این را به یک مونیتور تک‌نقطه‌ای تبدیل می‌کند و حکم ایران‌اکسس دیگر قابل صدور نیست. |
| `externalIntervalSecs` | عدد | `900` | کف ۳۰۰ و هرگز کمتر از `intervalSecs`. |
| `expectedStatus` | عدد یا null | `null` | مقدار `null` هر کد زیر ۴۰۰ را می‌پذیرد. |
| `expectedBody` | رشته یا null | `null` | جست‌وجوی زیررشته در بدنه پاسخ، بدون حساسیت به بزرگی و کوچکی حروف. |
| `iranNodes` | عدد | `3` | نودهای ایران، حداکثر ۸. مقدار `0` غیرفعالشان می‌کند. |
| `abroadNodes` | عدد | `4` | نودهای خارج، حداکثر ۸. |

تعداد نودها سقف است. از هر ASN ایرانی و هر کشور خارجی یک نود انتخاب می‌شود، پس درخواست بیشتر از تعداد
شبکه‌های متمایز فقط همه‌شان را به شما می‌دهد.

## spec سرور

```json
{
  "kind": "server",
  "host": "203.0.113.10",
  "port": 22,
  "username": "root",
  "auth": { "method": "key", "path": "~/.ssh/id_ed25519" },
  "hostFingerprint": "SHA256:hpQ0k9...",
  "loadLimit": 1.5,
  "memoryLimit": 85.0,
  "diskLimit": 85.0,
  "mounts": ["/", "/mnt/backup"],
  "containers": ["nginx", "postgres"]
}
```

| فیلد | نوع | پیش‌فرض | توضیح |
| --- | --- | --- | --- |
| `host` | رشته | الزامی | نام میزبان یا آی‌پی. |
| `port` | عدد | `22` | |
| `username` | رشته | الزامی | |
| `auth` | آبجکت | الزامی | پایین‌تر ببینید. |
| `hostFingerprint` | رشته یا null | `null` | اثر انگشت SHA256، در اولین اتصال خودکار نوشته می‌شود. برای ثبت مجدد `null` بگذارید. |
| `loadLimit` | عدد | `1.5` | میانگین بار یک دقیقه به ازای هر هسته. بالای سه برابر این، بحرانی. |
| `memoryLimit` | عدد | `85.0` | درصد. در ۹۷ بحرانی، مستقل از این مقدار. |
| `diskLimit` | عدد | `85.0` | درصد. در ۹۷ بحرانی، مستقل از این مقدار. |
| `mounts` | آرایه رشته | `["/"]` | مسیرهای مانت دقیقاً همان‌طور که `df` چاپ می‌کند. خالی به `["/"]` برمی‌گردد. |
| `containers` | آرایه رشته | `[]` | خالی بودنش دستور داکر را کاملاً حذف می‌کند. |

### auth

```json
{ "method": "key", "path": "~/.ssh/id_ed25519" }
{ "method": "password" }
```

`~/` نسبت به `HOME` باز می‌شود. نه رمز و نه عبارت عبور کلید اینجا ظاهر نمی‌شوند؛ هر دو در کی‌چین
زندگی می‌کنند.

## spec دامنه

```json
{
  "kind": "domain",
  "domain": "example.ir",
  "port": 443,
  "checkCertificate": true,
  "checkRegistration": true,
  "warnDays": 14
}
```

| فیلد | نوع | پیش‌فرض | توضیح |
| --- | --- | --- | --- |
| `domain` | رشته | الزامی | حروف کوچک می‌شود؛ اسکیم و اسلش انتهایی حذف می‌شوند. |
| `port` | عدد | `443` | برای هندشیک TLS. |
| `checkCertificate` | بولین | `true` | |
| `checkRegistration` | بولین | `true` | برای `.ir` بی‌اثر است، چون هیچ رجیستری‌ای این تاریخ را منتشر نمی‌کند. |
| `warnDays` | عدد | `14` | بین ۱ و ۱۲۰ محدود می‌شود. داخل یک‌سوم این مقدار، بحرانی. |

## تنظیمات

```json
{
  "language": "en",
  "desktopNotifications": true,
  "discordWebhook": null,
  "telegramChatId": null,
  "confirmations": 2,
  "startAtLogin": false
}
```

| فیلد | نوع | پیش‌فرض | توضیح |
| --- | --- | --- | --- |
| `language` | `"en"` یا `"fa"` | `"en"` | هر چیز دیگری به `"en"` برمی‌گردد. روی رابط کاربری و متن هشدارها اثر می‌گذارد. |
| `desktopNotifications` | بولین | `true` | حرف آخر را اجازه نوتیفیکیشن سیستم‌عامل می‌زند. |
| `discordWebhook` | رشته یا null | `null` | رشته خالی به `null` تبدیل می‌شود. |
| `telegramChatId` | رشته یا null | `null` | تلگرام فقط وقتی فعال است که این تنظیم شده باشد و توکنی ذخیره شده باشد. |
| `confirmations` | عدد | `2` | تعداد بررسی ناموفق پشت سر هم تا هشدار. بین ۱ و ۱۰ محدود می‌شود. |
| `startAtLogin` | بولین | `false` | تغییرش یک login item واقعی ثبت یا حذف می‌کند. |

## رمزها

رمزها هرگز در `targets.json` نوشته نمی‌شوند. به انبار اعتبارنامه پلتفرم می‌روند، زیر نام سرویس
`IranNANternet`:

| حساب | چه چیزی نگه می‌دارد |
| --- | --- |
| `target.<شناسه مورد>` | رمز SSH یا عبارت عبور کلید خصوصی |
| `notifications.telegram-token` | توکن ربات تلگرام |

- مک: Keychain، با Keychain Access قابل بازرسی است
- ویندوز: Credential Manager
- لینوکس: Secret Service، از طریق GNOME Keyring یا KWallet

حذف یک مورد رمزش را هم حذف می‌کند. کپی کردن `targets.json` به دستگاه دیگر موارد پایش را می‌برد ولی
رمزها را نه، که همان رفتار مورد نظر است؛ آنجا از نو واردشان کنید.

روی یک لینوکس بدون رابط گرافیکی و بدون ارائه‌دهنده Secret Service، ذخیره رمز شکست می‌خورد و سرورهایی
که با رمز احراز هویت می‌شوند `server.authenticationFailed` گزارش می‌دهند. موردهای مبتنی بر کلید با
کلید بدون رمزگذاری تحت تأثیر نیستند، چون به هیچ رمزی نیاز ندارند.

## زمان‌هایی که قابل تنظیم نیستند

عمداً ثابت هستند، چون در معرض گذاشتنشان یعنی در معرض گذاشتن یک راه برای خراب کردن برنامه:

| مقدار | کجا |
| --- | --- |
| حداقل بازه بررسی، ۱۵ ثانیه | هر مورد |
| حداقل بازه بررسی خارجی، ۳۰۰ ثانیه | وب‌سایت، برای رعایت محدودیت نرخ check-host |
| بازه استعلام ثبت دامنه، ۱۲ ساعت | دامنه، برای رعایت محدودیت نرخ رجیستری |
| کش فهرست نودهای check-host، ۶ ساعت | وب‌سایت |
| بودجه پول کردن نتیجه check-host، ۲۸ ثانیه | وب‌سایت |
| تایم‌اوت اتصال SSH، ۱۲ ثانیه | سرور |
| تایم‌اوت دستور SSH، ۲۵ ثانیه | سرور |
| تایم‌اوت اتصال TLS، ۲۰ ثانیه | دامنه |
| تایم‌اوت هندشیک TLS، ۱۵ ثانیه | دامنه |
| تایم‌اوت درخواست HTTP محلی، ۲۰ ثانیه | وب‌سایت |
| ارتقا به بحرانی در مصرف، ۹۷ درصد | حافظه و دیسک سرور |
| تیک زمان‌بند، ۱ ثانیه | همه |

زمان‌بند ثانیه‌ای یک بار بیدار می‌شود، هر موردی که زمان سررسیدش گذشته را اجرا می‌کند و هر بررسی را
به‌عنوان یک تسک مستقل می‌فرستد. پس یک سرور کند نمی‌تواند چیز دیگری را عقب بیندازد.

## ویرایش دستی بدون دردسر

۱. از منوی نوار وضعیت از برنامه خارج شوید. فقط بستن پنجره کافی نیست.
۲. از فایل بکاپ بگیرید.
۳. ویرایش کنید و JSON را معتبر نگه دارید. فایل غیرقابل پارس باعث می‌شود برنامه بدون هیچ موردی بالا
   بیاید و کرش نکند، ولی کسی نجاتش نمی‌دهد.
۴. برنامه را اجرا کنید و مطمئن شوید موردهایتان ظاهر می‌شوند.

اضافه کردن یک مورد با دست فقط به `name` و `spec` نیاز دارد؛ `id`، `enabled` و `intervalSecs` از
پیش‌فرض پر می‌شوند و شناسه اولین بار که برنامه ذخیره می‌کند ساخته می‌شود.
